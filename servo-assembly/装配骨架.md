## 怎么让它动

1. 右上角大纲视图展开 **7_骨架**
2. 点选 `M2_should` / `M3_elbow` 这类关节
3. 按 `N` 打开侧栏 → **Item → Transform → Rotation**
4. **只有该关节自己的轴能改**（其余两轴已锁死，填不进去），填角度即可
5. 下游整条臂自动跟着转

实测：M2 转 +30°，M5 末端从 `(354.5, 20.0, 104.5)` 变成 `(302.1, 20.0, -65.0)`，
与绕 M2 位置、世界 Y 轴旋转 30° 的理论值完全一致。

转 M1（偏航）时，M3 从 `(162.0, 0, 137.5)` 转到 `(118.1, 106.1, 137.5)` —— 整条臂绕立柱扫过 45°。

## 骨架怎么搭的（想改的时候看这里）

```
BASE_底座基准  Empty, 原点 (0,0,0)
└── M1_turn      轴标 + 标注 + 杆0
    └── M2_should   轴标 + 标注 + 杆1 + 杆2
        └── M3_elbow    轴标 + 标注 + 杆3 + 杆4
            └── M4_wp       轴标 + 标注 + 杆5
                └── M5_wy       轴标 + 标注
```

- **关节 Empty**：`PLAIN_AXES`，旋转模式 XYZ，非本轴方向全部上锁
- **轴标**：细圆柱（转轴）+ 圆盘（转动平面）合成一个物体，挂在关节下，local 原点
  - **绿色 = Y 轴**，**蓝色 = Z 轴**
- **标注**：挂在关节下，零位最准；转动幅度大时文字会跟着倾斜（故意的，这样它永远贴着关节）
- **连杆**：挂在"该段的起点关节"下，所以整段会跟着上游一起摆

## ⚠ 两个必须找学长确认的结构问题

### 1. M1 和 M2 完全重合

两者的世界坐标都是 `(12, 0, 117.5)`。**转台舵机和肩部舵机不可能占同一块空间。**

这不是我算错 —— MuJoCo 模型里 `L1_base_m2` 和 `L2_upper_a` 的 `body_pos` 就是 `(0,0,0)`，
说明当初推 M1 高度时，把"转台轴"和"肩轴"当成了同一个点。

可能的修正方向（需要学长拍板）：
- M1 下移到底座处，转台在下面转，肩在上面俯仰
- 或者承认 M2 就是"装在一个 L 型支架上的肩舵机"，M1 另找位置

### 2. 转台高度 117.5 与现有底座件对不上

M1 在 117.5mm 高处，而零件库里的 `底座_L型` 只有 **80.2mm** 高，中间差 **37.3mm**，
缺一段结构（立柱 / 垫高块 / 第二个舵机）。

装配前需要先确认这 37.3mm 用什么填。

## 装配建议顺序

1. **先定底座**：`底座_L型` 或 `舵机座_U型_Base`，原点对到 `BASE_底座基准`
2. **M1 转台舵机**：输出轴对准 Z，轴心落在 (12, 0, 117.5)
3. **M2 肩舵机**：输出轴对准 Y（绿盘方向）
4. **上臂**：150mm 铝管 + 20mm 竖直折
5. **M3 肘舵机** → **前臂 146mm** → **M4 腕舵机** → **M5 腕偏转舵机**

每装一个零件之前，先 `Object → Set Origin → Origin to 3D Cursor` 把原点移到关节轴心，
否则 `R` 转起来是绕几何中心打转。

---

## 一点说明

这套骨架是**运动学骨架**——只表达"关节在哪、绕什么转、每段多长"，不是结构件。
杆用 φ21mm 圆柱 + 关节球代替零件实体，因为它只需要告诉你尺寸，不需要长得像。

真正装零件时，把库里对应零件拖到关节位置，用顶点吸附对齐，再把零件 parent 到那个关节 Empty，
骨架要隐藏就关掉 `7_骨架` 这个 collection。

## 生成脚本

| 脚本 | 作用 |
|---|---|
| `build_skeleton.py` | 从零重建骨架 + 挪零件库 + 存盘 + 渲染零位图 |
| `verify_skeleton.py` | 验证父子链联动、关节锁、collection 可见性，渲染弯曲姿态 |
| `final_check.py` | 输出层级树与自定义属性核对表 |

改动前先看 `build_skeleton.py` 顶部的 `JOINTS` 和 `LINKS` 两个表，所有几何都在那里。
