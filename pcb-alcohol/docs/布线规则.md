## 3. 布线（禁止铺铜 → GND 必须靠走线）

### 3.1 线宽
| 网络 | 线宽 |
|---|---|
| +5V 主干、MQ-3 加热支路（172mA） | **0.8 mm** |
| 其它电源/GND 支线 | 0.5 mm |
| 信号（AOUT、OUT1~3、基准） | 0.3 mm（下限 0.254） |

### 3.2 顺序（照这个顺序走，20 分钟能布完）

1. **GND 干线**（底层，0.8mm）：从 J1.2 出发 → 沿 y≈16 横穿到板右侧 → 分 3 条支线下去/上去。
   所有 GND 点就近落到干线上（跨层用 Ø0.635/Ø1.2 过孔，环宽 0.28 ✓）。
2. **+5V**（顶层，0.8mm）：J1.1 → 沿 y≈23 向右 → 分岔给 U1.8/U2.8/MQ1.4,6/R5,R7,R9 上端/R2~R4/BZ1.1。
3. **AOUT**（底层 0.3mm，最短最直）：MQ1.1/3 → R1 与 C4 → 向右下贴 U1.2、U1.6 → 穿到底层再到 U2.2、U2.5 → J2.2。
   **AOUT 是唯一模拟量，避免与 +5V 长距离并行**。
4. **三个基准**（顶层 0.3mm）：分压中点 → 各自比较器的 IN+（U1.3 / U1.5 / U2.3），短线直连。
5. **OUT1~3**（顶层 0.3mm）：U1.1→R11→D1.K→J2.3；U1.7→R12→D2.K→J2.4；U2.1→R13→D3.K→J2.5。
6. **蜂鸣器支路**（顶层 0.5mm）：BZ1.2 → Q1.3；U2.7 → R14 → Q1.1。
7. 最后统一跑 DRC，再补丝印。

### 3.3 间距（DRC 里直接设这几个数）
| 项 | 值 |
|---|---|
| 最小线宽 | 0.254 |
| 最小线间距 | 0.254 |
| 走线-焊盘间距 | 0.254 |
| 焊盘边缘间距 | 0.254 |
| 焊盘中心间距 | 0.635 |
| 元件间距 | 0.508 |
| 焊盘到板边 | 0.254 |
| 过孔 | 孔 0.635 / 外径 ≥1.143（取 **1.2**） |
| 插件焊盘（自己放的） | 孔 1.20 / 盘 2.10 |

## 4. 丝印（14 分里的一项，别漏）

- **每个器件都有位号**（J1、U1、MQ1、R1…），字高 0.8~1.0mm，不要压在焊盘上
- J1 标 `USB-C 5V`；J2 标 `1-GND 2-AOUT 3-一档 4-二档 5-三档`（5 个数字必须标）
- D1/D2/D3 旁标 `一档/二档/三档`（或 1/2/3）
- MQ-3 旁标 `MQ-3 传感器`，蜂鸣器旁标 `BZ1`
- 板面留队伍号/日期也可以，但**不要遮挡焊盘**

## 5. 出图（Gerber）

1. 单位 mm，格式 RS-274X
2. 必须包含：**GKO（板框）、GTL（顶）、GBL（底）、DRL/TXT（孔）**
3. 文件名用"Altium 风格"最稳：`Gerber_BoardOutline.GKO`、`Gerber_TopLayer.GTL`、`Gerber_BottomLayer.GBL`、`Gerber_Drill_PTH.DRL`
4. 导出前**删掉所有铺铜**（专业版：选中铺铜 → Delete；或用"移除全部铺铜"）
5. 导出后立刻跑自检：

```bash
python tools/render_gerber.py --gerber <gerber目录> --out /tmp/chk   # 解析得动吗
python tools/verify_placement.py                                     # 坐标对得上吗
```

两条都过再打包。**这一步能拦住 20 分的 DRC 扣分项**。

## 6. 最后 10 分钟必查清单

- [ ] GKO 是 1 个闭合矩形，80×40，线宽一致，Keep-Out 层没有别的图案
- [ ] 4 个 Ø3 孔在 (5,5)(75,5)(5,35)(75,35)，是**过孔**形式
- [ ] Type-C 在左边中点、XH 在下边中点，插头方向不被元件挡
- [ ] MQ-3 与蜂鸣器在顶层，MQ-3 敏感面朝外
- [ ] 全板**没有一块铺铜**（这一项 −20）
- [ ] 每个网络都真的连上了（专业版：设计 → 检查 DRC → 未布线数量应为 0）
- [ ] 所有器件有丝印位号
- [ ] Gerber 4 类齐全，`pcb_check.py` 报 FAIL 0
- [ ] 命名：`【队伍号-原理图文件】.zip` + `【队伍号 PCB 设计文件】.zip`
