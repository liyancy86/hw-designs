# 嘉立创EDA **专业版** 操作手册（本赛专用）

> 走专业版路线。下面每条路径都来自官方文档（prodocs.lceda.cn / docs.lceda.cn），不是凭印象写的。
> 标 ⚠️ 的是"专业版和赛题说法不一致"的地方，最容易找错。

## 1. 赛前在家先做完这四件（10 分钟，现场省 20 分钟）

| # | 动作 | 为什么 |
|---|---|---|
| 1 | 导入 `嘉立创专业版库文件.elibz2` | 现场直接拖器件，不再折腾导入 |
| 2 | **导入 `XH254-5P_lib.elibz2`**（已含 `CONN-TH_5P-P2.54` + `XH2.54-5P` 器件 + 修好 3 个空封装引用） | 官方库里**没有**这个封装；补件已做好，**不用现场建** |
| 3 | 底部面板 → 器件/符号/封装 → **批量另存为**，导出成自己的 `.elibz2` 备份 | 换电脑/重装不丢，现场导入即用 |
| 4 | 在面板里设 **符号管理模式 = 简易模式**（设置 → 系统 → 通用） | 简易模式下"新建元件"就是符号+器件一起建，最快 |

> 第 3 步是关键保险：`elibz2` 是**库包**，能整包导入导出，比一个个拖器件可靠。

## 2. 导入官方 elibz2

两条路，任选：

- **路 A（推荐）**：先不打开工程 → 开始页 → **导入嘉立创EDA(专业版)** → 选 `嘉立创专业版库文件.elibz2` → 导入
- **路 B**：顶部菜单 → **文件 → 导入 → 嘉立创EDA(专业版)** → 选文件

导入时可**设置库分类**；如果弹"生成器件 / 仅符号 / 同时生成"，选 **生成器件**
（这个包里有 `device2.json`，导入后应直接得到 **16 个器件**，不是只有符号）。

导入成功后：底部面板 → **器件库 → 个人** → 能看到 `LM393DR2G`、`SEN-08880`、`KH-TYPE-C-2P`、`TMB12A05_C96093` 等。

> `.elibz2` 本质是 zip：`*.elibu`（行式 JSON，一个文档两段 DOCHEAD）+ `device2.json`（器件表）。
> 看到"这不是 zip 吗"不用慌，正常。

## 3. 画板框：在专业版里叫 **边框层**，不是 Keep-Out ⚠️

赛题原文说"板框画在 Keep-Out（导出后为 GKO）"——那是 **Altium 的说法**。专业版里对应关系是：

| 赛题说的 | 专业版里画在哪 | 导出成 |
|---|---|---|
| 板框 / Keep-Out | **边框层（Board Outline Layer）** | `Gerber_BoardOutline.GKO` |
| — | 机械层（Mechanical） | `Gerber_MechanicalLayer.GME` |

**三个必须记住的点：**

1. 别手工描 4 根线 —— 用 **放置 → 板框 → 矩形**，画完在右侧属性面板把 **宽 40 / 高 80（或 80/40）** 直接输进去。
   板框工具生成的框是**一条闭合折线、线宽统一**，正好满足"闭合 + 线宽一致 + 只有一个"三项要求。
2. **机械层千万别留闭合导线**。标准版文档明确写"机械层有闭合导线时，嘉立创生产会优先用机械层当板框"；
   专业版文档则说机械层不影响外形——两种说法都存在，**避开就绝不会错**（机械层只放工艺说明文字）。
3. 边框层上**除了这一个框，什么都不要画**（赛题明写"除边框外该层不能有任何图案"）。

## 4. 原理图 → PCB

1. 工程树里**右键 → 新建 PCB**（或 文件 → 新建 → PCB）。
2. 原理图画完先 **设计 → 检查 DRC**，再 **设计 → 原理图转PCB**（也叫"更新/转换原理图到PCB"）。
   弹窗里"确认导入信息"默认全勾，点 **应用修改**。
   ⚠️ 如果弹错，多半是**封装没指定**或**符号引脚编号 ≠ 焊盘编号**——封装管理器里补。
3. 之后每次改原理图：**设计 → 从原理图导入变更**（PCB 内），不要重复转新 PCB。
4. 摆件用坐标：`layout-routing.md` 给了 J1/J2/MQ1/BZ1 的绝对坐标。选中器件后在**右侧属性面板直接输入 X/Y**，比拖准。
5. 设计规则：**设计 → 设计规则**，把最小线宽 0.254 / 最小间距 0.254 / 过孔 0.635 先设好，DRC 才有意义。
6. 布线：**只用导线（Track），一根铺铜都不要**。

## 5. 改器件的"值"（缺口 A 的正解）

放置 `0805W8F1001T5E`（1K）→ 双击器件 → 右侧属性面板 → 把 **值** 改成 `4.7K` / `20K` / `30K` / `40K`。
符号和封装仍来自官方库，不违反"必须用组委会库"。详见 `library-gap.md` §3。

## 6. 导出 Gerber 与文件清单

顶部 **文件 → 导出 → Gerber** → 导出得到 zip，解压后（专业版 4.1 的命名）：

| 文件 | 内容 | 赛题要求 |
|---|---|---|
| `Gerber_BoardOutline.GKO` | 板框 | **必须** |
| `Gerber_TopLayer.GTL` | 顶层铜 | **必须** |
| `Gerber_BottomLayer.GBL` | 底层铜 | **必须** |
| `Drill_PTH_Through.DRL` | 金属化孔 | **必须** |
| `Gerber_TopSilkLayer.GTO` / `GBO` / `GTS` / `GBS` / `GTP` | 丝印/阻焊/钢网 | 顺带导出即可 |
| `Drill_PTH_Through_Via.DRL` | 过孔钻孔（嘉立创专用） | 一起留着 |

导出后**先跑自检，再打包**：

```bash
# 在本仓库根目录跑
python tools/render_gerber.py --gerber <解压后的gerber目录> --out /tmp/chk
python tools/verify_placement.py
```

第一条：能画出图 = 文件语法自洽、没有悬空指令。
第二条：`失败 0 项` = 坐标表真的落地到产物里了。

两条都过才允许打包。

## 7. 离线 / 在线

- 专业版**客户端可离线**跑，库文件是本地 `.elibz2`，导入不需要网络。
- 但"个人库"在客户端离线模式下存在**本地目录**；如果现场换机器，用 §1 第 3 步导出的库包最保险。
- 如果只装了网页版（pro.lceda.cn），必须登录 + 有网，**建议赛前确认客户端可用**。

## 8. 交付打包

```
【队伍号-原理图文件】.zip     ← 原理图源文件(.epro/.esch 或 .schdoc) + 原理图 PDF
【队伍号 PCB 设计文件】.zip   ← Gerber 文件夹(以队伍号命名) + PCB 源文件
```

PDF 名：`【队伍号-酒精浓度检测原理图】.pdf`，例 `1001-酒精浓度检测原理图.pdf`。
